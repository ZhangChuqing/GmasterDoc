# 串口读取数据故障排查

按以下顺序逐项排查：

## 1. 端口未被检测到

- 更换数据线（确认线材支持数据传输）
- 更换 USB 接口（A 口或 C 口）
- 避免使用扩展坞，直连电脑

## 2. 端口选择错误

确认软件中选择的 COM 口与设备管理器中显示的端口一致。

## 3. 驱动异常

打开设备管理器，查看端口是否有黄色警告图标。如有，右键 → 更新/安装驱动。

## 4. 波特率不匹配

发送端与接收端的波特率必须一致。常见值为 `115200`。

## 5. TX/RX 接反

- TX 接 RX
- RX 接 TX
- GND 接 GND

---

如果以上步骤全部排查后仍无法读取数据，请记录现象（截图、端口号、接线方式）并联系有经验的老队员协助排查。
