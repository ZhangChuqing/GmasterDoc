# 烧录故障排查

按以下顺序逐项排查：

## 1. OpenOCD 未找到

**现象**：

```
'openocd' 不是内部或外部命令，也不是可运行的程序
```

**原因**：系统环境变量中未配置 OpenOCD 路径。

**解决**：将 OpenOCD 所在目录添加到系统 PATH 环境变量中。

## 2. 烧录线序

确认烧录线序正确，详见 [烧录器文档](../开发/烧录器.md)。

## 3. 无线烧录器未配对

参考 [CMSIS-DAP 无线烧录器配对步骤](../开发/烧录器.md#2-cmsis-dap-无线烧录器)，确认主机与从机已完成配对并设置为相同信道。

## 4. 无线烧录器未上电

检查烧录器供电是否正常。

## 5. flash.cfg 烧录器类型错误

打开 `flash.cfg`，确认配置的烧录器类型与实际使用的一致（`stlink` 或 `cmsis-dap`）。

## 6. USB 连接问题

- 更换 USB 数据线（部分线材仅支持充电不支持数据传输）
- 更换 USB 接口（优先使用机箱背面直连接口，避免使用扩展坞）

## 7. 仍无法解决

若以上全部排查后仍无法烧录，怀疑硬件故障，请更换 C 板或烧录器后重试。
