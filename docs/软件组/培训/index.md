# 写在前面

在此特别感谢 2025 届邹绎达、陈乐鱼为我们 2026 届留下的珍贵培训文档。

培训是每个新成员成长的必经之路，过程会有点痛苦，但收获很大。如果你在培训里有没听懂的地方，欢迎来这里找对应的文档。

## 学习路线

这里的内容分三个阶段，建议照顺序学。

第一阶段是 [C 语言入门](./C++基础/index.md)。虽然文件夹沿用了历史名字，但这部分教的是 C 语言，从第一个程序讲起，一路到指针和内存。这条线索有意围绕"内存"展开：先认识变量是一个装数据的盒子，再看数组是排成一队的盒子，然后是指针（盒子的地址），最后把栈、堆、静态区这套完整的内存模型讲清楚。每个概念都出现在你正好需要它的位置。零基础不用怕，编程语言的骨架都相似，用心看、动手写，就能学会。

第二阶段是 [C++ 进阶](./C++进阶/index.md)。这里才是真正的 C++：面向对象、多态、模板、移动语义、智能指针、lambda 等，结合 GSRL 源码来讲。学这部分前，最好已经掌握了入门篇的指针和内存。

第三阶段是 [嵌入式基础](./嵌入式基础/index.md)。STM32 开发入门，从 GPIO 一路到 CAN 通信，最后是 GSRL 工程全景，13 个主题层层递进。
