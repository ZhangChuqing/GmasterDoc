# 判断语句：让程序做选择

没有判断，程序只能从头到尾按固定顺序走一遍，每次运行都一模一样。可现实中的逻辑几乎总要看情况办事：用户登录了就显示主页，没登录就显示登录界面；温度高就制冷，不高就不动。判断语句就是给程序这种"根据数据走不同路"的能力。C 语言提供两种判断机制，`if`-`else` 用于任意条件，`switch`-`case` 用于拿一个值和一串固定选项对照。

## if 语句

`if` 的形式很直接：括号里是一个条件，条件成立就执行后面大括号里的代码。

```c
int temperature = 35;

if (temperature > 30) {
    printf("天气炎热，开启制冷\n");
}
```

如果还想在条件不成立时做另一件事，加上 `else`：

```c
if (temperature > 30) {
    printf("开启制冷\n");
} else {
    printf("制冷未开启\n");
}
```

当情况不止两种，可以用 `else if` 串起多个分支，程序从上往下逐个检查，命中哪个就执行哪个，之后不再往下看：

```c
int score = 85;

if (score >= 90) {
    printf("等级：A\n");
} else if (score >= 80) {
    printf("等级：B\n");
} else if (score >= 70) {
    printf("等级：C\n");
} else if (score >= 60) {
    printf("等级：D\n");
} else {
    printf("等级：F\n");
}
```

这里有个容易忽略的点：条件是从上到下依次判断的，所以顺序不能乱。`score` 为 85 时，先撞上 `>= 80` 就输出 B 并停下，正因为 `>= 90` 那一关它没过。

## 条件的真假是怎么判定的

C 语言判定真假的规则朴素得出人意料：值为 `0` 就是假，任何非零值（`1`、`-1`、`42` 都算）就是真。C 本身没有独立的布尔类型，真假就是用整数表示的。

这条规则解释了一些常见的简写。判断一个标志变量时，直接写 `if (flag)` 就等价于 `if (flag != 0)`；判断指针是否为空时，`if (!ptr)` 等价于 `if (ptr == NULL)`，因为空指针 `NULL` 的值就是 0。

```c
int flag = 1;
if (flag) {          // 等价于 if (flag != 0)
    printf("flag 为真\n");
}

int* ptr = NULL;
if (!ptr) {          // 等价于 if (ptr == NULL)
    printf("指针为空\n");
}
```

## 大括号别省

`if` 后面如果不写大括号，只有紧挨着的那一条语句归它管，再往下的语句无论条件真假都会执行。这个规则常常坑到人，尤其是后来往里加代码的时候。

```c
// 危险写法：只有 printf("及格") 属于 if
if (score > 60)
    printf("及格\n");
    printf("恭喜\n");   // 这行其实和 if 无关，永远都会执行

// 安全写法：始终用大括号框住
if (score > 60) {
    printf("及格\n");
    printf("恭喜\n");
}
```

即使循环体只有一行，也建议保留大括号。它几乎不增加负担，却能防止日后添加代码时无意间破坏逻辑。

## switch-case 语句

当同一个变量要和好几个固定的值逐一比较时，写一长串 `if`-`else if` 会显得啰嗦，`switch` 更清爽。它拿括号里的值去和各个 `case` 标签比对，命中哪个就从哪里开始执行。

```c
int day = 3;

switch (day) {
    case 1:
        printf("星期一\n");
        break;
    case 2:
        printf("星期二\n");
        break;
    case 3:
        printf("星期三\n");
        break;
    case 4:
        printf("星期四\n");
        break;
    case 5:
        printf("星期五\n");
        break;
    default:
        printf("周末\n");
        break;
}
```

关键在于每个 `case` 末尾的 `break`。`switch` 只负责跳到匹配的 `case` 开始执行，并不会在下一个 `case` 处自动停下。`break` 的作用就是跳出整个 `switch`。一旦漏写，程序会一路"穿透"到下一个 `case` 继续执行，这往往不是本意。

```c
int n = 1;
switch (n) {
    case 1:
        printf("一\n");
        // 这里没有 break，会继续掉进 case 2
    case 2:
        printf("二\n");
        break;
}
// 输出：
// 一
// 二
```

不过穿透有时是有意为之。把几个 `case` 标签叠在一起、中间不放代码，就表示它们共用后面同一段处理逻辑，这比给每种情况都写一遍要简洁：

```c
char grade = 'B';
switch (grade) {
    case 'A':
    case 'B':
    case 'C':
        printf("通过\n");   // A、B、C 共用这段
        break;
    case 'D':
    case 'F':
        printf("未通过\n");
        break;
}
```

`switch` 有几条硬性限制需要记住：括号里的表达式必须是整数类型（`int`、`char`、`enum` 都行，`float` 和 `double` 不行）；每个 `case` 后面跟的必须是常量，不能是变量或表达式；它只认相等，判断不了"大于""在某范围内"这类条件。

## 嵌套与合并

判断可以嵌套，一个 `if` 里面再套 `if`。经典的例子是闰年判断——能被 4 整除、但不能被 100 整除，或者能被 400 整除：

```c
int year = 2024;

if (year % 4 == 0) {
    if (year % 100 == 0) {
        if (year % 400 == 0) {
            printf("%d 是闰年\n", year);
        } else {
            printf("%d 不是闰年\n", year);
        }
    } else {
        printf("%d 是闰年\n", year);
    }
} else {
    printf("%d 不是闰年\n", year);
}
```

但嵌套一深，可读性就急剧下降，超过三层基本就没人能一眼看懂了。这时应该考虑把逻辑用逻辑运算符合并，或者拆成独立函数。上面的闰年判断合并之后清楚得多：

```c
if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
    printf("%d 是闰年\n", year);
} else {
    printf("%d 不是闰年\n", year);
}
```

## 什么时候用哪个

`if` 和 `switch` 并非二选一的对立，各有各的地盘。凡是条件涉及范围（`x > 10`）、牵扯多个变量、或者要比较浮点数的，只能用 `if`-`else if`，因为 `switch` 只会做整数的等值比较。反过来，当一个整数变量要和一串离散常量对照、分支又比较多时，`switch` 结构更清晰，编译器还可能把它优化成跳转表，效率更高。分支很少（比如就两三个）的简单场合，直接 `if`-`else` 就够了，不必动用 `switch`。

## 条件运算符

对于"二选一赋值"这种最简单的分支，条件运算符 `?:` 比整段 `if`-`else` 紧凑得多：

```c
// 用 if-else
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}

// 用条件运算符，一行搞定
int max = (a > b) ? a : b;
```

它的便利仅限于简单情形。一旦嵌套起来就很难读，这种时候老实拆成 `if`-`else if` 或函数反而更好：

```c
// 不推荐：嵌套的条件运算符像绕口令
int result = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

// 推荐：拆开写，一目了然
int result;
if (a > b && a > c)      result = a;
else if (b > a && b > c) result = b;
else                     result = c;
```

## 几个反复出现的坑

初学者最容易踩的是把比较写成了赋值：`if (x = 5)` 用的是赋值 `=`，它会把 5 赋给 x 再判断这个结果的真假（非零即真），恒为真，本意其实是比较 `if (x == 5)`。编译器通常会对此发出警告，留意警告能救你一次。

数学里的连写在 C 中不成立。`if (0 < x < 10)` 不会判断 x 是否在 0 到 10 之间，而是先算 `0 < x` 得到 0 或 1，再拿这个结果和 10 比，永远为真。正确写法是用逻辑与连接两个条件：`if (x > 0 && x < 10)`。

还有一类是多余的分号。`if (x > 0);` 后面那个分号本身就是一条空语句，`if` 的真正主体反倒被这个空语句占了，后面的大括号成了无条件执行的独立代码块。`switch` 里漏写 `break` 造成意外穿透，`case` 后面误用变量，也都是常见错误，前面已经分别讲过。
