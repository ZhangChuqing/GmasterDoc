# 循环语句：让程序重复干活

程序里经常要把一件事重复做很多遍。如果没有循环，重复就只能靠复制粘贴——打印一百次就得写一百行，既笨拙又没法应对次数会变的情况。

```c
printf("第 1 次\n");
printf("第 2 次\n");
printf("第 3 次\n");
// 要一百次就得写一百行
```

循环把这件事交给程序自己去重复，几行代码就能顶替上面那一大片：

```c
for (int i = 1; i <= 100; i++) {
    printf("第 %d 次\n", i);
}
```

C 语言提供 `for`、`while`、`do`-`while` 三种循环，它们能做的事其实是等价的，区别在于哪种写法在什么场景下最顺手。

## for 循环

`for` 把控制循环的三件事集中写在了括号里，这是它最大的特点：

```c
for (初始化; 条件; 更新) {
    // 循环体
}
```

三部分各司其职：初始化在循环开始前执行一次，通常用来设定计数器；条件在每一轮循环体之前检查，为真才继续；更新在每轮循环体之后执行，通常用来推进计数器。执行顺序是这样的：

```
初始化 → 判断条件 → 执行循环体 → 执行更新 → 判断条件 → 执行循环体 → 执行更新 → ...
         ↑_____________循环____________|
```

拿一个最常见的例子把每一轮拆开看：

```c
for (int i = 0; i < 5; i++) {
    printf("i = %d\n", i);
}
// 输出：i = 0, i = 1, i = 2, i = 3, i = 4
```

```
第 1 轮：i = 0 → 判断 0 < 5 为真 → 输出 i=0 → i++（i 变为 1）
第 2 轮：i = 1 → 判断 1 < 5 为真 → 输出 i=1 → i++（i 变为 2）
第 3 轮：i = 2 → 判断 2 < 5 为真 → 输出 i=2 → i++（i 变为 3）
第 4 轮：i = 3 → 判断 3 < 5 为真 → 输出 i=3 → i++（i 变为 4）
第 5 轮：i = 4 → 判断 4 < 5 为真 → 输出 i=4 → i++（i 变为 5）
第 6 轮：i = 5 → 判断 5 < 5 为假 → 结束循环
```

三部分都可以灵活变化：计数器可以递减、可以按大于 1 的步长跳跃、也可以同时维护多个变量。甚至每一部分都能省略（分号必须留着），无限循环 `for (;;)` 就是三部分全空。

```c
// 递减
for (int i = 10; i > 0; i--) {
    printf("%d\n", i);     // 10, 9, 8, ..., 1
}

// 步长为 2
for (int i = 0; i < 10; i += 2) {
    printf("%d\n", i);     // 0, 2, 4, 6, 8
}

// 多个变量
for (int i = 0, j = 10; i < j; i++, j--) {
    printf("i=%d, j=%d\n", i, j);
}

// 省略某些部分
int i = 0;
for (; i < 10; i++) { ... }    // 初始化放到了循环外

for (int i = 0; i < 10; ) {    // 更新放到了循环体内
    printf("%d\n", i);
    i++;
}

for (;;) {                     // 无限循环，等价于 while(1)
    // ...
}
```

在括号里直接声明计数器（`for (int i = 0; ...)`）是 C99 起才支持的，这样 `i` 的作用域仅限于循环内部，循环一结束它就消失，不会污染外面。更早的 C89/C90 标准不允许这么写，得先在循环外声明 `int i;` 再使用。

## while 循环

`while` 只有一个条件，先判断，为真才执行循环体，执行完再回来判断，如此往复。

```c
while (条件) {
    // 循环体
}
```

因为是先判断后执行，如果条件一开始就为假，循环体一次都不会执行。

```c
int count = 5;
while (count > 0) {
    printf("倒计时：%d\n", count);
    count--;
}
// 输出：5, 4, 3, 2, 1
```

`for` 和 `while` 能相互替代，但各有更适合的场合。次数事先确定的，比如遍历一个已知长度的数组，用 `for` 把计数逻辑集中起来最清爽。而次数事先说不准、要靠运行时的情况来决定何时停的，用 `while` 更自然，比如逐字符读到文件末尾，或者反复接收输入直到满足某个条件为止：

```c
// 逐字符读取直到文件结束
int ch;
while ((ch = getchar()) != EOF) {
    putchar(ch);
}

// 反复猜直到猜中
int guess;
printf("猜数字（1-100）：");
scanf("%d", &guess);
while (guess != 42) {
    printf("不对，再试：");
    scanf("%d", &guess);
}
printf("正确！\n");
```

## do-while 循环

`do`-`while` 和 `while` 几乎一样，唯一的区别是它把条件判断挪到了循环体之后：先无条件执行一次循环体，再判断要不要继续。

```c
do {
    // 循环体
} while (条件);
```

这个差别的意义在于：无论条件是否成立，循环体都保证至少执行一次。最典型的用途是输入验证——总得先让用户输入一次，才谈得上检查这次输入合不合格。

```c
int input;
do {
    printf("请输入正数：");
    scanf("%d", &input);
} while (input <= 0);

printf("你输入了：%d\n", input);
```

三种循环的差异可以横向对照如下：

| 特性 | `for` | `while` | `do`-`while` |
|------|-------|---------|--------------|
| 最少执行次数 | 0 | 0 | **1** |
| 适用场景 | 已知循环次数 | 循环次数不确定 | 至少执行一次 |
| 典型用法 | 遍历数组、计数器 | 读取文件、等待条件 | 输入验证、菜单交互 |
| 条件检查位置 | 循环体之前 | 循环体之前 | 循环体之后 |

选择的思路也简单：知道要循环几次就用 `for`；不知道、且可能一次都不用执行就用 `while`；不知道、但至少要执行一次就用 `do`-`while`。

## break 与 continue

正常情况下循环靠条件来结束，但有时需要在循环体中途改变节奏，这就是 `break` 和 `continue` 的用武之地。`break` 立即终止整个循环，跳到循环之后的第一条语句；`continue` 只跳过本轮剩下的代码，直接进入下一轮的条件判断，循环并不结束。

```c
// break：撞到 5 就整个停下
for (int i = 0; i < 10; i++) {
    if (i == 5) {
        break;
    }
    printf("%d ", i);
}
// 输出：0 1 2 3 4

// continue：偶数就跳过本轮，只打印奇数
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) {
        continue;
    }
    printf("%d ", i);
}
// 输出：1 3 5 7 9
```

有一点要特别注意：`break` 只能跳出它所在的那一层循环。在嵌套循环里，内层的 `break` 只结束内层，外层照常继续。

```c
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break;  // 只跳出内层这个 for
        printf("(%d,%d) ", i, j);
    }
}
// 输出：(0,0) (1,0) (2,0)
```

如果确实需要一举跳出所有循环，可以借助一个标志变量，或者在这类少数情况下使用 `goto`。

## 几种常见写法

日常写循环，有几个模式会反复出现，熟悉它们能少走弯路。

遍历数组是最基本的，用 `sizeof` 算出元素个数，再从 0 到个数减 1 依次访问：

```c
int arr[] = {10, 20, 30, 40, 50};
int n = sizeof(arr) / sizeof(arr[0]);

for (int i = 0; i < n; i++) {
    printf("%d ", arr[i]);
}
```

累加求和是在循环外准备一个初值为 0 的变量，循环里不断往上加：

```c
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
printf("1 到 100 的和 = %d\n", sum);  // 5050
```

查找元素时，一旦找到就用 `break` 停下，没必要把剩下的元素走完；再用一个标志变量记录到底找没找到：

```c
int arr[] = {3, 7, 2, 9, 5};
int target = 9;
int found = 0;

for (int i = 0; i < 5; i++) {
    if (arr[i] == target) {
        printf("找到了，索引 = %d\n", i);
        found = 1;
        break;
    }
}
if (!found) {
    printf("未找到\n");
}
```

还有一种是主动写一个无限循环，把退出条件放在循环体内部，满足了才 `break`，常见于命令行菜单这类交互：

```c
while (1) {
    int cmd;
    printf("输入命令（0 退出）：");
    scanf("%d", &cmd);
    if (cmd == 0) break;
    printf("执行命令 %d\n", cmd);
}
```

## 几个容易犯的错

循环相关的错误里，出现频率最高的是行末多写了一个分号。`for (...);` 或 `while (...);` 后面那个分号会被当成一个空的循环体，真正想循环的代码块反而成了只执行一次的独立块。这种错误编译器往往不报，行为却完全跑偏，很难查。

另一类是循环停不下来。要么是更新语句没有正确改变循环变量，条件永远为真；要么是数组遍历时把 `i < n` 写成了 `i <= n`，多走一轮访问到了不存在的元素，造成越界。写循环时确认一下循环变量每轮都在朝终止条件靠近，边界用 `<` 还是 `<=` 想清楚，能避开大部分这类问题。
