# 运算符

有了变量和数据类型，程序就能存放数据，但只存不算没有意义。运算符解决的正是"怎么算"的问题——它们是对数据进行计算、比较、组合的符号。C 语言的运算符相当丰富，真正需要费心的不是记住每一个符号的写法，而是理解它们混在一起时谁先算、往哪个方向算，这才是写出正确表达式的关键。

## 算术运算符

加减乘除和取模是最基础的一组。前四个符合直觉，需要留意的是除法和取模在整数上的行为。

```c
int a = 10, b = 3;

int sum    = a + b;    // 加 → 13
int diff   = a - b;    // 减 → 7
int prod   = a * b;    // 乘 → 30
int quot   = a / b;    // 除 → 3（整数除法，截断小数）
int remains = a % b;   // 取模（求余数）→ 1
```

两个整数相除，结果仍是整数，小数部分被直接截断，这一点在上一章讲数据类型时已经强调过。它容易坑人的地方在于，截断发生在赋值给浮点变量之前，所以 `float y = 10 / 3;` 得到的是 3.0 而不是 3.33。要得到真正的小数结果，必须让参与运算的操作数中至少有一个是浮点类型。

```c
int   x = 10 / 3;    // x = 3（整数除法）
float y = 10 / 3;    // y = 3.0（先做整数除法 10/3=3，再转为 3.0）

// 正确获取小数结果的方式：
float z1 = 10.0f / 3.0f;           // 直接用浮点数字面量
float z2 = (float)10 / 3;           // 将整数显式转换为浮点类型
float z3 = 10.0f / 3;               // 混合类型时自动提升
```

取模运算 `%` 求的是余数，它只能用于整数，对 `float` 或 `double` 取模是非法的。还有一个细节：结果的符号跟随被除数，而不是除数。

```c
int r1 =  10 % 3;   // 1
int r2 = -10 % 3;   // -1（被除数为负，结果也为负）
int r3 =  10 % -3;  // 1（被除数为正，结果为正）
```

## 关系运算符与逻辑运算符

关系运算符用来比较两个值，逻辑运算符则把多个比较的结果组合起来，二者的产物都是一个布尔意义上的真假：C 语言里用 `1` 表示真，`0` 表示假。关系运算符有六个，含义与数学里的符号一致：`==` 等于、`!=` 不等于，以及 `>`、`<`、`>=`、`<=`。逻辑运算符有三个，`&&` 是与（两侧都为真才为真），`||` 是或（有一侧为真即为真），`!` 是非（真假反转）。

初学者最容易栽的跟头，是把赋值的 `=` 和比较的 `==` 搞混。`if (x = 5)` 并不是在判断 x 是否等于 5，而是先把 5 赋给了 x，再拿这个非零的结果当条件，于是永远为真。想比较必须写 `if (x == 5)`。

逻辑运算符还有一个重要特性叫短路求值：对 `&&` 来说，只要左侧为假，整个表达式已注定为假，右侧就不再计算；对 `||` 来说，左侧为真时右侧同样被跳过。这个特性不只是省一点时间，更常被用来写"守卫条件"——先确认指针非空，再去访问它指向的内容，顺序颠倒就会解引用空指针。

```c
// && 短路：左侧为假时，右侧不会执行
if (p != NULL && *p == 42) {  // 安全：p 为空时不会解引用
    // ...
}

// || 短路：左侧为真时，右侧不会执行
if (index < 0 || index >= size) {  // 任一条件满足即判定越界
    // ...
}
```

## 位运算符

前面的运算都作用在整个数值上，位运算符则直接操作二进制的每一位，常见于底层编程、驱动、以及需要精打细算的性能场合。它一共有六个，用 `a=5`（二进制 0101）、`b=3`（二进制 0011）作例子最直观：

| 运算符 | 含义 | 示例（`a=5(0101), b=3(0011)`） |
|--------|------|-------------------------------|
| `&` | 按位与 | `a & b` → 1（0101 & 0011 = 0001） |
| `\|` | 按位或 | `a \| b` → 7（0101 \| 0011 = 0111） |
| `^` | 按位异或 | `a ^ b` → 6（0101 ^ 0011 = 0110） |
| `~` | 按位取反 | `~a` → -6（~00000101 = 11111010） |
| `<<` | 左移 | `a << 1` → 10（0101 → 1010，乘 2） |
| `>>` | 右移 | `a >> 1` → 2（0101 → 0010，除 2） |

位运算最典型的用途是标志位：用一个整数的不同二进制位分别代表若干个开关，通过按位或来打开某位、按位与配合取反来关闭某位、按位与来检测某位。此外，左移右移相当于乘以或除以 2 的幂，比普通乘除更快。

```c
// 1. 标志位操作（用一个整数的不同位表示多个开关）
#define FLAG_A  0x01    // 0001
#define FLAG_B  0x02    // 0010
#define FLAG_C  0x04    // 0100

int flags = 0;
flags |= FLAG_A;         // 打开 FLAG_A
flags &= ~FLAG_B;        // 关闭 FLAG_B
if (flags & FLAG_C) {    // 检测 FLAG_C 是否打开
    // ...
}

// 2. 高效率乘除 2 的幂
int x = 10;
int y = x << 3;   // 等价于 x * 8（前提是不溢出）
int z = x >> 2;   // 等价于 x / 4
```

要特别当心的是别把 `&` 和 `&&`、`|` 和 `||` 写混。前者按位操作，后者是带短路特性的逻辑运算，一个字符之差，结果可能天壤之别。

## 赋值、自增与自减

赋值运算符除了基本的 `=`，还有一系列复合形式，把运算和赋值合二为一，`x += 5` 就是 `x = x + 5` 的简写。算术和位运算都能这样复合。

```c
int x = 10;

x += 5;    // x = x + 5  → 15
x -= 3;    // x = x - 3  → 12
x *= 2;    // x = x * 2  → 24
x /= 4;    // x = x / 4  → 6
x %= 4;    // x = x % 4  → 2

x <<= 2;   // x = x << 2
x &= 0x0F; // x = x & 0x0F
```

自增 `++` 和自减 `--` 让变量加一或减一，但它们有前置和后置两种写法，区别在于"先变还是先用"。前置的 `++a` 先把 a 加一，再拿新值参与表达式；后置的 `a++` 先用 a 当前的值，之后才加一。

```c
int a = 5;
int b = ++a;    // 前置自增：a 先加 1，再赋值给 b → a=6, b=6
int c = a++;    // 后置自增：先赋值 a 给 c，a 再加 1 → c=6, a=7
```

正因为前后置的时机不同，把它们塞进复杂表达式里（例如 `arr[i++] = ++j`）极易让人读错，甚至引发未定义行为。稳妥的做法是拆成独立的语句，清晰远比省一行重要。

## 条件运算符

条件运算符 `? :` 是 C 语言里唯一需要三个操作数的运算符，因而也叫三元运算符。它按 `条件 ? 为真时的值 : 为假时的值` 求值，本质上是 `if-else` 的表达式版本，适合简单的二选一赋值。

```c
int max = (a > b) ? a : b;

// 等价于：
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

它写起来紧凑，但一旦嵌套就会迅速变得难以辨认，所以只在简单场景使用，复杂的分支还是老实写 `if-else`。

## sizeof

`sizeof` 是一个常被忽略却很实用的运算符，它返回某个类型或变量在当前机器上占用的字节数。类型各占几字节不必死记，用它打印出来最可靠。

```c
printf("%zu\n", sizeof(int));      // 类型的大小
printf("%zu\n", sizeof(x));        // 变量的大小（可省略括号）
printf("%zu\n", sizeof(arr));      // 数组的总大小（元素数 × 每个元素大小）
```

## 优先级与结合性

当一个表达式里出现多个运算符时，优先级决定谁先算，就像数学里先乘除后加减；当优先级相同，结合性决定运算从左往右还是从右往左进行。C 语言的优先级层级很多，完整表格可供查阅，但没有必要背下来。

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1（最高） | `()` `[]` `->` `.` `++`（后置） `--`（后置） | 左到右 |
| 2 | `!` `~` `++`（前置） `--`（前置） `+`（正） `-`（负） `*`（解引用） `&`（取地址） `sizeof` | 右到左 |
| 3 | `*` `/` `%` | 左到右 |
| 4 | `+` `-` | 左到右 |
| 5 | `<<` `>>` | 左到右 |
| 6 | `<` `<=` `>` `>=` | 左到右 |
| 7 | `==` `!=` | 左到右 |
| 8 | `&`（按位与） | 左到右 |
| 9 | `^` | 左到右 |
| 10 | `\|`（按位或） | 左到右 |
| 11 | `&&` | 左到右 |
| 12 | `\|\|` | 左到右 |
| 13 | `?:` | 右到左 |
| 14 | `=` `+=` `-=` 等赋值符 | 右到左 |
| 15（最低） | `,`（逗号） | 左到右 |

真正要记住的只有一条实用准则：拿不准优先级时就加括号。位运算的优先级尤其反直觉，`a & mask == mask` 会先算 `==` 再算 `&`，几乎不是你想要的意思，写成 `(a & mask) == mask` 既正确又让意图一目了然。括号优先级最高，多打一对括号从不吃亏。
