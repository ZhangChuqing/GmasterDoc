# 输入与输出

程序要有用，就得能和外界交换数据：从键盘或文件读进信息，再把结果显示出来。这就是输入输出要解决的问题。C 语言把这件事交给标准库，其中最基础的一对函数是 `printf` 和 `scanf`，它们都定义在 `<stdio.h>` 里，一个负责向屏幕输出，一个负责从键盘读入。

## 输出：printf

`printf` 的第一个参数是一个格式字符串，除了原样输出的文字，里面还可以嵌入以 `%` 开头的占位符，运行时这些占位符会被后面依次给出的参数替换掉。

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!\n");                  // 输出纯文本
    printf("年龄：%d 岁\n", 25);                 // 带占位符
    printf("姓名：%s，分数：%.1f\n", "张三", 95.5); // 多个占位符
    return 0;
}
```

占位符的字母对应着数据的类型，用错会导致输出错乱。常用的有：`%d` 或 `%i` 输出有符号十进制整数，`%u` 输出无符号整数，`%f` 输出 `float` 或 `double`，`%c` 输出单个字符，`%s` 输出字符串，`%x` 和 `%X` 以小写或大写输出十六进制，`%o` 输出八进制，`%p` 输出指针地址。此外 `%%` 用来输出一个百分号本身。`%lf` 在 `printf` 里和 `%f` 等价，但在 `scanf` 里读 `double` 时必须用它，这一点后面会再提。

占位符还能附带格式控制，用来指定宽度、对齐和精度。在 `%` 和类型字母之间插入数字：`%6d` 表示这个整数至少占 6 个字符宽，不足时右侧对齐、左边补空格；加上负号变成 `%-6d` 则改为左对齐；把空格换成 0，写成 `%06d`，不足的位就用 0 填充。对浮点数，`%.2f` 表示保留两位小数，`%10.3f` 则是总宽 10 位、小数 3 位。

```c
int    n = 42;
double pi = 3.1415926535;

printf("|%d|\n",   n);        // |42|
printf("|%6d|\n",  n);        // |    42|  （右对齐，6 字符宽度）
printf("|%-6d|\n", n);        // |42    |  （左对齐）
printf("|%06d|\n", n);        // |000042|  （用 0 填充）

printf("|%f|\n",   pi);       // |3.141593|  （默认 6 位小数）
printf("|%.2f|\n", pi);       // |3.14|      （保留 2 位小数）
printf("|%10.3f|\n", pi);     // |     3.142|（总宽 10，3 位小数）
```

格式字符串里还有一类以反斜杠开头的转义序列，用来表示无法直接打出的字符：`\n` 是换行，`\t` 是制表符，`\\` 输出一个反斜杠，`\"` 和 `\'` 分别输出双引号和单引号。

## 输入：scanf

`scanf` 和 `printf` 形式相似，但有一个本质区别：它要把读到的值写回变量，因此必须知道变量在内存里的位置，也就是要传变量的地址，而不是变量本身。这就是为什么 `scanf` 的参数前几乎总要加取地址符 `&`。

```c
int age;
printf("请输入年龄：");
scanf("%d", &age);                // 注意 & 取地址符！
printf("你输入的年龄是：%d\n", age);
```

忘记写 `&` 是初学者最常犯的 `scanf` 错误。理解了它的原理——`scanf` 需要地址才能修改变量——就不容易漏掉。一次读入多个值时，占位符之间通常靠空白字符分隔，`scanf` 默认会把空格、换行、Tab 都当作分隔符。

```c
int    id;
float  score;
char   grade;

printf("输入学号 成绩 等级（空格分隔）：");
scanf("%d %f %c", &id, &score, &grade);
```

`scanf` 有一个容易被忽视的返回值：它返回成功匹配并赋值的项数。借助它可以判断用户是否输入了合法数据，比如期望读入一个整数，若返回值不是 1，就说明输入格式有问题。

```c
int result = scanf("%d", &x);
if (result == 1) {
    printf("成功读取一个整数：%d\n", x);
} else {
    printf("输入格式错误！\n");
}
```

`scanf` 的坑集中在几处，值得单独记一下。忘记 `&` 前面已经说过。另一个高频问题是残留的换行符：先用 `%d` 读一个整数，回车留下的换行符会被紧接着的 `%c` 读走，解决办法是在 `%c` 前加一个空格，写成 `scanf(" %c", &ch)`，这个空格会跳过前面所有的空白。读字符串时 `%s` 默认不限长度，存在缓冲区溢出的风险，应写成 `%49s` 之类限定最大长度。至于类型不匹配，比如用户给 `%d` 输入了字母，正是靠检查返回值来发现。

## 单字符输入输出

当只需要处理一个字符时，`getchar` 和 `putchar` 比 `scanf` 和 `printf` 更轻便，前者从标准输入读一个字符，后者往标准输出写一个字符。

```c
char ch = getchar();   // 从标准输入读取一个字符
putchar(ch);           // 向标准输出写入一个字符
putchar('\n');
```

一个经典写法是逐字符回显直到遇到换行或文件结束。这里有个细节容易被忽略：接收 `getchar` 结果的变量要用 `int` 而不是 `char`，因为文件结束标志 `EOF` 通常是 -1，用 `char` 可能无法正确区分它和普通字符。

```c
int ch;                        // 注意：用 int 而非 char，
while ((ch = getchar()) != '\n' && ch != EOF) {  // 因为 EOF 通常是 -1
    putchar(ch);
}
```

## printf 与 scanf 的对照

这两个函数长得像，但方向和用法上有几处关键差异，放在一起对比最清楚。

| 对比项 | `printf` | `scanf` |
|--------|----------|---------|
| 方向 | 程序 → 屏幕 | 键盘 → 程序 |
| 参数 | 传值 | 传地址（`&var`） |
| 格式串 | 可含文字和占位符 | 通常只含占位符 |
| `double` 占位符 | `%f` 即可 | 必须 `%lf` |
| 返回值 | 输出的字符数 | 成功匹配的项数 |

## 一个完整的例子

把输入、输出和上一章的运算符串起来，可以写一个简易计算器：读入"数 运算符 数"的算式，根据运算符算出结果。其中除法特意判断了除数是否为零，这是数值程序里必须防的一类错误。

```c
#include <stdio.h>

int main()
{
    double a, b;
    char op;

    printf("请输入算式（格式：数 运算符 数）：");
    scanf("%lf %c %lf", &a, &op, &b);

    switch (op) {
        case '+': printf("%.2f + %.2f = %.2f\n", a, b, a + b); break;
        case '-': printf("%.2f - %.2f = %.2f\n", a, b, a - b); break;
        case '*': printf("%.2f * %.2f = %.2f\n", a, b, a * b); break;
        case '/':
            if (b != 0.0)
                printf("%.2f / %.2f = %.2f\n", a, b, a / b);
            else
                printf("错误：除数不能为零\n");
            break;
        default:
            printf("不支持的运算符\n");
    }

    return 0;
}
```

这段代码里的 `scanf("%lf %c %lf", ...)` 也再次印证了前面那条规则：读 `double` 必须用 `%lf`，而在上面的 `printf` 里用 `%f` 就够了。
