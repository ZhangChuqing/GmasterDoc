# 数据类型：盒子有多大、装什么

上一章把变量理解成一个装数据的盒子。这一章回答紧接着的两个问题：盒子有多大，里面的东西该怎么读。这就是数据类型的作用。

## 类型规定了两件事

声明变量时写的那个类型，比如 `int`、`char`、`float`，是在向编译器说明两件事。

一是盒子的大小。`int` 通常占 4 个字节，`char` 占 1 个字节。盒子越大，能装下的数值范围越大。

二是内容的读法。计算机内存里存的全是 0 和 1，一段二进制本身没有含义，是类型决定了如何解释它。同一段数据，按整数读是一个值，按小数读是另一个值。类型相当于一张翻译表，规定了用哪张表去读这段二进制。

因此，类型并不改变数据本身，它只决定盒子的大小以及内容的读法。取值范围、字面量后缀这些细节，都是从这两点推导出来的。

## 整数

最常用的整数类型是 `int`，占 4 个字节，能表示大约正负 21 亿之间的整数。日常的计数、循环、数组下标，用 `int` 即可。

21 亿这个范围并非硬记：一个字节 8 个二进制位，4 个字节就是 32 位，可表示 2³² 个不同的值，正负各占一半，正向便到约 21 亿。范围由字节数决定——盒子越大，能表示的数越大。

其余整数类型只是盒子大小不同：`char` 1 字节，`short` 2 字节，`long long` 8 字节。需要更大的数值范围，就选更大的类型。

`long` 是个例外，需要留意。它在不同系统上大小不一致：Windows 上 4 字节，Linux 和 macOS 的 64 位系统上 8 字节。当程序依赖某个整数的确切位数时，不要用 `long`，而应选用 `int32_t`、`int64_t` 这类名字里直接标明位数的类型（需 `#include <cstdint>`），这样跨平台不会改变。

整数还分有符号和无符号。默认的 `int` 能表示正负数；前面加上 `unsigned` 后只能表示非负数，但正向范围翻倍。当一个值在逻辑上不可能为负时（例如数组长度），适合用无符号类型。但无符号数的减法存在一个陷阱：`unsigned` 的 0 减去 1 不是 -1，而会绕回成一个极大的数。因此只要运算中可能出现负数或负的差值，就应使用有符号的 `int`。

## 浮点数

整数装不下小数，小数需要浮点类型。常用的是 `float`（4 字节）和 `double`（8 字节），后者精度更高，能保留更多有效数字。

浮点数有一个必须了解的特性：它并不精确。计算机用二进制存储小数，而许多常见的十进制小数换算成二进制是无限循环的，无法完整存下，只能截断，于是产生微小误差。例如 0.1 加 0.2，结果未必正好是 0.3，而可能是 0.30000000000000004。

这一特性带来一条实用准则：不要用 `==` 判断两个浮点数是否相等，因为它们可能只相差极小的一点。应改为判断二者之差是否足够小。

```cpp
if (fabs(x - 0.3f) < 1e-6f) {
    // 差距小到可以忽略，视为相等
}
```

此外，小数字面量默认是 `double` 类型；若要表示 `float`，需在数字后加后缀 `f`，如 `3.14f`。选择上，一般优先用 `double` 以保证精度，只有在数据量很大、内存或带宽紧张时，才为节省空间选用 `float`。

## 字符

`char` 用来存一个字符，比如 `'A'`。但它的本质是一个 1 字节的整数——内存里存的是一个数字，"字符"只是这个数字按 ASCII 表翻译后呈现给人的形式。

```cpp
char ch = 'A';          // 内存里存的其实是数字 65
printf("%c\n", ch);     // 按字符翻译，输出 A
printf("%d\n", ch);     // 按整数输出，是 65
```

理解了这一点，许多现象便不难解释：`'A' + 1` 等于 `'B'`（65 加 1 是 66，正好是 B），字符之间能比较大小，值为 0 的字节可用来标记字符串的结尾。它们背后都只是整数运算。

## sizeof

上述各类型的字节数无需死记，也不必猜测。运算符 `sizeof` 会直接给出某个类型在当前机器上占几个字节。

```cpp
sizeof(int);    // 通常是 4
sizeof(long);   // Windows 上 4，Linux 64 位上 8
```

对某个类型的大小存疑时，用 `sizeof` 打印出来，比查文档更快也更可靠。

## 类型之间的转换

不同类型一起运算时，编译器会自动转换。从小盒子转到大盒子是安全的，比如 `int` 转 `double`，数值不会丢失；反过来从大转小可能丢失信息，编译器通常会给出警告。

初学者最常见的坑是整数除法。两个整数相除，结果仍是整数，小数部分被直接舍去，而且这一步发生在赋值给浮点变量之前。

```cpp
int a = 10, b = 3;
double c = a / b;          // 先算 10÷3=3（整数除法，舍去小数），再变成 3.0，结果是错的
double d = (double)a / b;  // 先把 a 转成小数，触发浮点除法，得到 3.333
```

整数除以整数始终是整数除法，要得到小数结果，必须先把其中一个操作数转成浮点类型。
