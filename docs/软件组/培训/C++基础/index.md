# C 语言入门

这部分教 C 语言，面向零基础或想把基础打扎实的同学。文件夹名字是历史遗留的，内容其实是纯 C，从第一个能跑起来的程序讲起，一直到指针和内存。

整条线索是围绕"内存"来安排的。C 语言的核心就是内存：数据放在哪、占多大、怎么读。所以我们不急着一上来就讲内存模型，而是让它自然浮现——

先认识变量，把它理解成一个装数据的盒子；再看数据类型，也就是盒子有多大、里面的位怎么解释；然后是数组和字符串，那是一排紧挨着的盒子，你第一次真切看到数据在内存里的排布；接着是指针，也就是盒子的地址，这是 C 语言真正的核心；最后把栈、堆、静态区这套完整的内存模型讲透，前面所有铺垫在这里收束。

每个概念都安排在你正好需要它的位置，照编号顺序读就行。别只看不写，学的时候自己动手敲几个小程序，才真的记得住。
