# C++ 进阶

本部分在 C++ 基础之上，深入讲解面向对象编程、内存模型、模板、智能指针、移动语义等 C++ 核心机制，并结合 GSRL 源码实例帮助理解。

建议在学习完 [C++ 基础](../C++基础/index.md) 后阅读本部分。其中 **指针** 和 **内存** 是理解后续所有主题的基石，建议优先阅读。
