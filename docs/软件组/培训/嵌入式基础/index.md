# 嵌入式基础

本部分系统讲解 STM32 嵌入式开发的核心知识，从 MCU 的基本概念出发，逐步深入 GPIO、中断、通信协议（UART/SPI/I2C/CAN）、定时器、传感器等主题，最终以 GSRL 工程结构全景图收尾。

建议在学习完 [C++ 基础](../C++基础/index.md) 后，按编号顺序阅读。本系列与 GSRL 源码紧密结合，每个主题都会说明其在机器人控制中的实际应用场景。
